# 台灣行政區房價與租金

台灣本島各縣市、鄉鎮市區的房價與租金資料網站。

網站目前提供：

- 中位數房價
- 平均租金
- 房價／所得比
- 縣市篩選
- 行政區搜尋

---

## 資料來源

主要資料來源：

### 內政部不動產交易實價查詢服務網

https://lvr.land.moi.gov.tw/

用於取得：

- 房屋買賣交易
- 房屋租賃交易
- 成交價格
- 成交單價
- 租金
- 行政區資料

### 內政部不動產資訊平台

https://pip.moi.gov.tw/

用於取得：

- 房價所得比
- 房價相關統計
- 不動產市場相關指標
